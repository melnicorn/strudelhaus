Tool pages use the whole window

The sandbox and lesson pages lose their 1600px cap. Sidebars keep a fixed width; the centre (editor + controls) takes everything else. Prose pages (Learn, About, home) stay as centred 1280px columns, since long lines of text get hard to read. Sounds, Library, Reference and Dictionary were already the wide kind (a fixed list or sidebar beside a table or card grid), so they go full width with the tool pages.
