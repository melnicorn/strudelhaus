Sound-board controls: a catalog

Every control below is a replica of what you'd find on a drum machine or a small mixer, drawn for the instrument panels (block panels, transport, arrangement). They're all live here: drag knobs and faders up/down, click pads and switches, use ↑/↓ on a focused knob. The page chrome (lessons, library, dialogs, menus) would stay as it is.

Rule kept from today: the number is always visible. A knob with no readout hides the value that's in the code, and the code is the source of truth. Every knob has a small readout under it that is also a text field: click it (or press Enter on a focused knob), type a number, Enter commits, Esc cancels. Double-click the knob to reset to the default. Mobile is not a target for now.

3 · Knobs

One rotary control, four flavours. Unipolar (gain), bipolar with a centre detent (pan, transpose, filter envelope), logarithmic (cutoff: the arc is log so the useful 200–2k range isn't crammed into a corner), and stepped (octave: the pointer snaps to detents). Drag vertically, ↑/↓ to nudge, ⇧ for coarse. Scroll wheel is not bound: it would hijack page scrolling.

A pattern value like "0.8 0.6" (mini-notation in a number slot) can't be a knob. Those keep the mono text field, with the knob greyed and a tiny "pattern" LED, as the slider does today.

4 · Faders

Vertical level faders for the mixer view (one per part), with M / S underneath. Better than knobs for gain because relative levels can be read across parts at a glance. The arrangement matrix could sit above these as a channel strip.

5 · Switches and selectors

Fixed choices stop being dropdowns when there are five options or fewer: a slide switch (filter type), a two-position toggle (voicing on/off, swing on/off), and a rotary selector for the classic drum machines. Trade-offs

Today (HeroUI sliders)Sound-board
PrecisionGood: a long track, the value in a fieldKnobs are coarser per pixel; fine moves need ⇧ or the arrows. Readout stays, so you can still see 0.72.
DensityOne row per parameter: panels get tall5–6 knobs per row: panels get wide and short, which suits the full-width layout
DiscoverabilityLabels read like a formReads like gear: matches the lessons' vocabulary (cutoff, resonance, decay) and the 909 colours teach the beat grouping
AccessibilityReact Aria slider: keyboard + screen reader for freeMust be rebuilt on the same React Aria useSlider hook so nothing is lost; the look is CSS/SVG on top
TouchFineVertical drag on a knob fights page scrolling on phones; needs touch-action: none and bigger hit areas
ThemeFollows light/darkInstrument surfaces are always dark (like the code area); the page around them still follows the theme
